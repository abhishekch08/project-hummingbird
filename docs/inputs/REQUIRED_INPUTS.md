# External inputs and decision queue

CH03–CH06 parameterized models are complete at conditional-math gates. These are still **missing physical/product inputs** for a real architecture, runtime, peak-current, transport, memory, clock/timing or frozen host ABI verdict. Do not fill missing values with asserted vendor numbers.

CH02 numeric rates and LED output current are traceable *scenario* values in `specs/system/CH02_MODE_ASSUMPTIONS.json`. CH03–CH06 input files contain **synthetic** cell/rail/load, packet/link/storage, clock/trigger/IMU and host frame/register values for arithmetic verification. None substitutes for the missing measurements above; feature-only CH04 output discards raw evidence unless a reviewed product decision permits it.
